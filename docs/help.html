Help

What Desk sends, what it costs in memory, where it keeps things, and what to do when something goes wrong.

Privacy

Desk has no account, no telemetry and no server. It does not read or store Claude tokens. It makes two kinds of network connection, and only these:

  • the update check against github.com/1oNN/claude_desk releases, in the installed app, unless you turn it off;
  • ssh to a remote machine, only if you set one up (below).

Claude Code itself talks to Anthropic as it always does.

Memory

Measured on Windows 11 with this version, using Electron's own process metrics:

Private memoryWorking set
Desk idle, no sessionsabout 200 MBabout 510 MB
Each extra windowabout 45-50 MBabout 124 MB
Each shell, in Desk's main processabout 11 MB
Each Claude session (Windows process list)762-1,107 MB354-490 MB

The sessions are what fill memory, not Desk. On one Desk running seven Claude sessions, Desk's own processes were 479 of 3,771 MB working set (13%) and the Claude sessions 2,903 MB. Rewriting Desk in another language would not change that: Claude Code is its own program and stays the same size. Stopping a session you are not using saves 354-490 MB each.

  • By default Desk starts only the sessions that were in the panes of the project you were last on. The rest show a Resume button. Settings, Sessions, Start with Desk changes this.
  • A pane hidden for a minute drops its terminal buffer and gets the last 128 KB back when shown again.
  • Settings, Sessions, Graphics set to Software drops the GPU process, about 100 MB.
  • Memory per session puts each session's size in the sidebar.

Updates

The installed app checks GitHub Releases a little after it starts and every six hours after that. A new version downloads in the background and installs when you close Desk. Settings, Updates shows your version, has a Check now button and can turn the check off. A copy run from source never updates itself; use git pull.

Settings and data

Settings are saved in settings.json in Desk's data folder:

  • installed: %APPDATA%\Claude Desk\
  • from source: state\ in the repo folder

That folder also holds accounts.json, desk.json (projects, sessions, windows and layout) and desk.log, which says what Desk did and why. Help, Open the state folder goes there.

An environment variable wins over the saved value:

VariableSets
DESK_PROJECTSthe projects folder
DESK_CLAUDEthe Claude Code executable
DESK_PWSHthe shell
DESK_STATE_DIRthe data folder
DESK_NO_UPDATEset to 1 to skip the update check

A remote machine

Optional. Desk can also run sessions on a Linux or macOS machine over ssh, inside tmux, and show them next to your local ones. You need ssh key login, tmux and claude on that machine. Add these to settings.json:

{
  "remoteHost": "mybox",
  "remoteProjects": "projects",
  "laptopAccounts": [1, 2]
}

remoteHost is a Host entry in your ~\.ssh\config. remoteProjects is a folder under the remote home. laptopAccounts lists the account ids that may run there. Account 1 uses the remote's own ~/.claude; any other account gets ~/.claude-desk/accounts/<id> and signs in the first time it starts. Host keys are checked against your known_hosts.

Troubleshooting

Claude Code was not found

Setup's Check step and the Welcome page say so. Install Claude Code so that claude works in a terminal, or set its path in Settings, Paths (or DESK_CLAUDE).

I cannot select text in a Claude pane

Claude Code turns on mouse reporting, so a plain drag goes to Claude Code. Hold Shift while you drag to select, then Ctrl+C or right click to copy.

An account shows no usage

That account has its own statusLine in its Claude Code settings, and Desk leaves it alone. Remove it there if you want Desk's usage bars.

A session says it is open elsewhere

It was started outside Desk in the same folder, or it is shown in another Desk window. Close the outside copy, or click the session to go to the window that has it.

The window is too small to use

Under 900 wide the sidebar opens over the panes; Ctrl+B toggles it. View, Reset zoom (Ctrl+Shift+0) puts the window zoom back to 100%.

Known issues

Windows onlyThe window frame, the shells and the account junctions are Windows code.
Unsigned installerSmartScreen warns on first install until the app is code signed.
Mouse in Claude CodeSelecting text needs Shift held; right click pastes rather than opening a menu.
MemoryEach Claude session is its own process at 350-490 MB working set, so eight panes of Claude is several GB. The power icon on a pane stops one you are done with.

Reporting a problem

Open an issue with what you did, what you expected and what happened, and attach desk.log (Help, Open the log). For a security problem, see SECURITY.md.
