# Code of conduct

Be civil in issues, pull requests and discussions. Criticise code and ideas, not people.
No harassment, slurs, sexual content or personal attacks, and no posting other
people's private information.

The maintainer may edit or remove comments, lock threads and block accounts that break
this. To report something, use GitHub's "Report content" option on the comment, or
open a private report from the Security tab if it cannot be said in public.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
