Setup

Where Desk looks for things on this PC. Saved in the state folder; a DESK_* environment variable wins over it.

Claude Code
Shell
Accounts

Each account is a Claude Code sign-in with its own folder. Sign in runs Claude Code's own login in a pane; Desk never reads or stores a token.

Context

What Desk adds to each session's system prompt. It is sent with every message.

Updates

Start

Which saved sessions start with Desk. A Claude session takes 400 MB or more of RAM, a shell about 100 MB. The rest wait in their pane with a Resume button.

Graphics. Software painting drops the GPU process, about 100 MB, and uses the CPU instead. The window looks the same. Applies at the next start.

Text

Every part zooms on its own. Hold Ctrl and turn the mouse wheel over a terminal to size that terminal's text and nothing else, or over the sidebar, the top bars, the status bar or home to zoom only that part. Ctrl+= and Ctrl+- do the same for what has focus, and Ctrl+0 puts it back.

Window, everything at once (Ctrl+Shift+= and Ctrl+Shift+-, or the buttons at the bottom right).

Terminal text, for every terminal you have not sized on its own.

Appearance

Accent, for the focused pane, buttons and the cursor.

Terminal font. A font that is not installed falls back to Cascadia Mono.

Sidebar

Drag its right edge to resize. Ctrl+B hides and shows it, Ctrl+Shift+B or the panel button at the bottom left hides the icons too.

Attention

A session that needs you shows on the bell, in the window title and at the top of Desk home with how long it has waited.

Keys
Ctrl+K
command palette: say, new session, panes, views, theme
Ctrl+P
jump to a session or project
Ctrl+Shift+N
new Claude session in this project
Ctrl+Shift+T
new shell in this project
Ctrl+1 to 8
focus that pane
Ctrl+Shift+1 to 8
one to eight panes
Ctrl+Tab
next session in the pane
Ctrl+Shift+Tab
previous session in the pane
Ctrl+B
hide or show the sidebar
Ctrl+Shift+B
hide or show the whole left panel, icons too
Ctrl+,
settings
Ctrl+wheel
zoom what is under the pointer: one terminal, the sidebar, the top bars, the status bar or home. The rest stays as it is
Ctrl+= and Ctrl+-
zoom what has focus, the terminal you are typing in; Ctrl+0 puts it back
Ctrl+Shift+= and Ctrl+Shift+-
zoom the whole window; Ctrl+Shift+0 back to 100%
Ctrl+C
in a terminal, copies when text is selected, otherwise stops the program as usual
Ctrl+V or right click
paste into the terminal; right click copies instead when text is selected
Ctrl+click
open a web link printed in a terminal
Ctrl+/ or F1
this list as a card
Esc
close a menu, the palette or the keys card, or clear the toasts
In the sidebar
Up and Down move, Enter opens, Right reaches a row's buttons or expands, Left collapses, Delete stops

Everything else reaches the terminal. F12 opens the developer tools.
